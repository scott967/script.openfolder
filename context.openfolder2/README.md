# This Kodi addon is for Kodi Matrix (v19) and up
Install as addon from zip file.  It will appear in Kodi addons
as a "context menu".  When a Kodi media item is focused, opening
the item's contxt menu will show a new entry "Open item folder".
Clicking this menu item will open a Windows file explorer window
at the item's folder location.  (Not tested on other platforms
but should work)
